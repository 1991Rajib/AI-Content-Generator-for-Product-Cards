01. Executive Summary & Problem Statement

Modern e-commerce merchants spend substantial time writing compelling product titles, conversion-focused descriptions, and SEO keyword hashtags for their catalog. The objective of Assignment 2: AI Content Generator for Product Cards is to engineer a web application that takes minimal merchant inputs (Product Name and Category), leverages generative AI via a REST API, and renders the result as an interactive, styled product card.

02. System Architecture & Data Flow

To ensure professional enterprise security, this project employs a Serverless Proxy Pattern on Vercel rather than exposing API keys directly in client-side code.

┌────────────────────────────────────────────────────────────────────────────────────────┐ │ CLIENT (React 19 + Vite) │ │ - User submits Product Name + Category + Tone │ │ - Triggers Loading Skeleton & optimistic UI updates │ │ - Renders interactive ProductCard with 1-click copy for Description, Tags & JSON │ └───────────────────────────────────────────┬────────────────────────────────────────────┘ │ POST /api/generate ▼ ┌────────────────────────────────────────────────────────────────────────────────────────┐ │ VERCEL SERVERLESS FUNCTION (/api/generate.js) │ │ - Reads process.env.GEMINI_API_KEY from secure Vercel environment variables │ │ - Validates input payload and injects JSON schema prompt guidelines │ │ - Enforces responseMimeType: "application/json" for zero markdown parsing errors │ └───────────────────────────────────────────┬────────────────────────────────────────────┘ │ HTTPS REST Call ▼ ┌────────────────────────────────────────────────────────────────────────────────────────┐ │ GOOGLE GEMINI 1.5 FLASH REST API │ │ - Generates SEO title (under 60 chars), persuasive description & keyword array │ └────────────────────────────────────────────────────────────────────────────────────────┘
Security Best Practice: By routing AI calls through /api/generate.js, the Gemini API key is never bundled into client JavaScript. For evaluators running the Vite dev server locally without Vercel, the app includes an in-app API settings modal and an intelligent demo engine fallback.

03. AI REST Integration & Prompt Engineering

The backend uses the Google Gemini 1.5 Flash endpoint (gemini-1.5-flash:generateContent). To eliminate fragile string manipulation or markdown backtick parsing, the API is configured with strict JSON schema enforcement: 

{
  "title": "A captivating, benefit-driven product title (under 60 characters)",
  "shortDescription": "A persuasive, punchy description highlighting key benefits (25-45 words)",
  "tags": ["keyword1", "keyword2", "keyword3", "keyword4", "keyword5", "keyword6"],
  "category": "Selected Category",
  "estimatedPrice": "$79.99",
  "bulletPoints": ["Feature 1", "Feature 2", "Feature 3"],
  "badge": "Best Seller | Editor's Choice | Eco-Friendly"
}

04. State Management & Component Architecture

The application follows a clean unidirectional data flow without unnecessary third-party state bloat:

  • App.jsx (Root Coordinator): Manages activeCard, isLoading, error, history, and customApiKey. Automatically hydrates recent cards from localStorage.
  • ProductForm.jsx: Manages local input states, category choices, presets, and validation. Emits a clean payload to onGenerate().
  • ProductCard.jsx: Visual presenter displaying high-resolution category photography, star ratings (4.9/5), product badges, copy-to-clipboard helpers, and price suggestions.
  • CardSkeleton.jsx: Pulse-animated skeleton matching the exact dimensions of the card to prevent layout shift (CLS).
  • HistoryDrawer.jsx: Renders a history grid allowing users to switch between recently generated cards.

05. Vercel Deployment & Environment Configuration

The project is pre-configured with vercel.json for seamless zero-config deployment:

Deploying to Vercel in 3 Steps:

  1. Push to GitHub: Commit the workspace and push to your GitHub repository.
  2. Import into Vercel: In Vercel Dashboard, select "Add New Project" and choose the repository.
  3. Add Environment Variable: Under Environment Variables, enter:
    GEMINI_API_KEY = <your-google-gemini-api-key>
  4. Click Deploy: Vercel builds the React client and sets up the serverless /api/generate endpoint automatically.
